# Remaining work

These files are the product requirements still to be built. Each file describes one capability: who it is for, what the library must remember, who may do it, and how to tell it is done.

The suggested pace is in [the intern roadmap](../intern-roadmap.md).

1. [Add an author](01-add-an-author.md) — record a writer once, with a unique name.
2. [View an author](02-view-an-author.md) — open one author that is already on file.
3. [Search authors](03-search-authors.md) — page through authors and narrow the list by name.
4. [Update an author](04-update-an-author.md) — correct an author without breaking uniqueness.
5. [Remove an author](05-remove-an-author.md) — remove an author who no longer has books.
6. [Tie books to authors](06-tie-books-to-authors.md) — a book names an author the catalog already knows.
7. [Add a book](07-add-a-book.md) — add a book under the catalog field rules.
8. [View a book](08-view-a-book.md) — open one book that is already on file.
9. [Search the catalog](09-search-the-catalog.md) — page through books and narrow by title, author, or ISBN.
10. [Remove a book](10-remove-a-book.md) — remove a book that nobody currently has on loan.
11. [Borrow a copy](11-borrow-a-copy.md) — a member takes one available copy for 14 days.
12. [Return a copy](12-return-a-copy.md) — a returned copy becomes available again.
13. [Review overdue loans](13-review-overdue-loans.md) — see loans still out past their due date.
14. [Review accounts](14-review-accounts.md) — an administrator sees accounts, never passwords.
15. [Change a person's role](15-change-a-persons-role.md) — set someone to member, librarian, or administrator.
16. [Suspend or restore an account](16-suspend-or-restore-an-account.md) — a suspended account cannot sign in.
17. [Renew a session](17-renew-a-session.md) — stay signed in without typing the password again.
18. [Review activity](18-review-activity.md) — see who changed the catalog, loans, and accounts, and when.
19. [Slow repeated sign-in failures](19-slow-repeated-sign-in-failures.md) — repeated bad passwords are refused for a cooling-off period.
20. [Reset a forgotten password](20-reset-a-forgotten-password.md) — set a new password once, from a link that expires.
21. [Confirm an email address](21-confirm-an-email-address.md) — a new account cannot sign in until the email is confirmed.
