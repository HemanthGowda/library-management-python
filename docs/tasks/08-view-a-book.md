# View a book

**Status:** Not built

## Who this is for

A signed-in person needs to open one book and read the catalog record, including how many copies are free.

## Requirement

Anyone who is signed in can open a single book that is already on file.

## Information

The view shows the title, author, ISBN, description, publication year, total copies, and available copies. An empty description is shown as empty.

## Who may do this

- Member, librarian, and administrator: yes
- Anyone who is not signed in: no

## Rules

- The book must already exist.
- An unknown book is refused, and the reason says the book was not found.
- Opening a book does not change the record or the copy counts.

## Done when

- A member, a librarian, and an administrator can each open a book and see the saved details and copy counts.
- Anyone who is not signed in is refused.
- An unknown book is refused, and no book record changes.
